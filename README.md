# Planificador de Tareas

Aplicación web para organizar y dar seguimiento a tareas personales. Es el proyecto individual del Bootcamp Full Stack Java (Generation Colombia) y crece sprint a sprint: primero la interfaz (HTML, CSS, Bootstrap y JavaScript) y después el backend (Java, Spring Boot y base de datos SQL).

## Metodología

El trabajo se organiza con Scrum en un tablero de Trello. Cada sprint tiene un objetivo claro, y el progreso se registra con commits pequeños y frecuentes.
